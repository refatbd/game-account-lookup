# Security policy

## Reporting

Report vulnerabilities privately to the repository maintainer through the
security-advisory feature of:

https://github.com/refatbd/game-account-lookup/security/advisories/new

Do not include real customer UIDs, cookies, access tokens, API keys, or provider
credentials in a public issue.

## Supported versions

Until the first stable release, only the latest `main` branch is supported.
After `1.0.0`, the latest minor release will receive security fixes.

## Scope

Security reports may include:

- Credential or token exposure.
- Server-side request forgery.
- Unsafe TLS behavior.
- Sensitive debug logging.
- Cache isolation problems.
- Input validation bypass.
