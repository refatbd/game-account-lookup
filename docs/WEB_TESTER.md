# Web Test Template

The [`template/`](../template/) directory is a runnable development application for checking the package before publishing it to GitHub or Packagist.

## Features

- Package/PHP/cURL health indicator
- Searchable list of all registry definitions
- Conditional zone/server input
- Automatic provider fallback, all-provider comparison or strict single provider
- Live lookup and offline deterministic demo mode
- Normalized account card and complete provider-diagnostics table
- Upstream HTTP status, duration, host, retry/ray data, Codashop regional route and sanitized previews
- Maintenance-state warning and live-submit blocking for non-active games
- Raw JSON display and copy action
- Browser-only recent history
- File-backed successful-result cache
- Per-request cache bypass without clearing stored entries
- Basic local rate limiting
- No external CSS/JavaScript dependency

The tester UI itself has no frontend dependency. Free Fire and PUBG Mobile may
still invoke the optional local browser-assisted providers during live automatic
lookup. Those routes require Node.js 22+, Chrome/Edge and PHP `proc_open`; see
the main README's Browser-assisted providers section. Select a PHP-only provider
explicitly when running in a non-interactive environment.

## Run

```bash
php -S 127.0.0.1:8080 -t template
```

Open `http://127.0.0.1:8080`.

The template first uses `vendor/autoload.php`; if Composer has not been run, it falls back to the repository's local `src/` directory.

## Test flow

1. Confirm the API status is green.
2. Load the Free Fire sample UID `4422076728` or choose another game.
3. Turn on **Demo mode** to verify form validation, result rendering, attempts, JSON copying and history without a network request.
4. Turn off Demo mode for an actual provider check.
5. Test at least one zone-required game and confirm the form prevents missing zone input.
6. Force each configured provider separately, then test automatic fallback.
7. Select **All providers** and confirm every configured provider returns its own row and JSON object.
8. Repeat a successful lookup and confirm the result shows local cache.
9. Enable **Bypass cache** and confirm the same ID is fetched live again.

## Endpoints

### `GET /api/health.php`

Reports PHP version, required extensions, registry counts and demo availability.

### `GET /api/games.php`

Returns sanitized `GameRegistry::list()` output. It never exposes provider secrets.

### `GET|POST /api/check.php`

Fields:

| Field | Required | Meaning |
|---|:---:|---|
| `game` | Yes | Canonical code or alias |
| `player_id` | Yes | Player UID/account ID |
| `zone_id` | Conditional | Required by zone/server games |
| `provider` | No | Empty for fallback, `__all__` for all, or one provider key |
| `demo` | No | `1` to avoid upstream calls |
| `bypass_cache` | No | `1` to skip cache read and write for this request |

## Provider execution modes

| Selection | Behavior |
|---|---|
| Automatic fallback | Runs hosting-safe registry order (Garena for Free Fire, GoPay/classic Codashop, dynamic, browser) and stops after success |
| All providers | Runs every configured provider and displays every response |
| Only `<provider>` | Runs exactly one provider and disables fallback |

All-provider responses include `summary`, `provider_results` and `attempts`.
Each `provider_results` item contains the full normalized response from that
provider, including nickname, provider code, cache state, error information and sanitized upstream diagnostics. Region-aware Codashop attempts also show the selected `codashop_profile` and the complete `profile_attempts` route.

Enable **Bypass cache** to skip both cache reading and cache writing for the
current request. Existing cache files are not deleted.


## HTTP status policy

A completed lookup request returns HTTP `200` even when every external provider
fails. This prevents Cloudflare or a reverse proxy from replacing the useful
JSON with a generic gateway page. Read `ok`, `code`, `attempts` and
`provider_results` to determine the lookup outcome.

Input/method/rate-limit errors generated by the local template can still return
appropriate `4xx` status codes.

## Regional Codashop profiles

For games configured with `codashop_dynamic`, the diagnostics table displays the
regional profile and a route such as `malaysia-en:PROVIDER_RESTRICTED ->
indonesia-id:SUCCESS`. Enable **Bypass cache** when comparing routes. See
[`CODASHOP_REGIONAL_ROUTING.md`](CODASHOP_REGIONAL_ROUTING.md).

## Maintenance states

Definitions whose status is not `active` do not perform live requests. The API
returns `MAINTENANCE_REQUIRED` with `game_status` and `maintenance_notes`; the
browser disables live submission but allows Demo mode.

## Configuration

Edit [`template/config.php`](../template/config.php) or set environment variables documented in [`template/README.md`](../template/README.md).

## Security boundary

The tester is intended for local development. Its file rate limiter trusts the direct remote address and is not a replacement for production proxy-aware throttling. Before public deployment, add authentication, framework validation, persistent cache, production monitoring, trusted proxy configuration and an explicit provider/legal review.
